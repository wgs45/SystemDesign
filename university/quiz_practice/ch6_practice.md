# Key OOP Concepts 🌸

## Class vs Object

| Concept | Meaning                              |
| ------- | ------------------------------------ |
| Class   | Blueprint/template                   |
| Object  | Actual instance created from a class |

Example:

- **Class:** CAR
- **Object/Instance:** Red Mustang

---

## Core Object-Oriented Principles

| Principle     | Meaning                                    |
| ------------- | ------------------------------------------ |
| Encapsulation | Keeps data and methods together            |
| Inheritance   | Allows objects/classes to inherit features |
| Polymorphism  | Same action behaves differently            |
| Abstraction   | Hides unnecessary details                  |
