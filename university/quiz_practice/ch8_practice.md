# Important Exam Concepts 🌸

## Data Validation Rules

| Validation Rule      | Purpose                                |
| -------------------- | -------------------------------------- |
| Existence Check      | Required field cannot be empty         |
| Range Check          | Value must be within a specified range |
| Validity Check       | Value must follow predefined rules     |
| Sequence Check       | Data follows the correct order         |
| Reasonableness Check | Detects unusual but possible values    |

### Example

| Input                            | Validation              |
| -------------------------------- | ----------------------- |
| Age = (blank)                    | Existence Check ❌      |
| Age = 250                        | Range Check ❌          |
| Gender = X (not allowed)         | Validity Check ❌       |
| Salary = NT$5,000,000 for Intern | Reasonableness Check ⚠️ |

---

## Common Report Types

| Report Type          | Purpose                                |
| -------------------- | -------------------------------------- |
| Detail Report        | Shows complete records                 |
| Summary Report       | Shows summarized information           |
| Exception Report     | Shows only unusual or selected records |
| Control Break Report | Groups records by a control field      |

---

## Security Concepts

| Concept              | Purpose                      |
| -------------------- | ---------------------------- |
| Encryption           | Protects sensitive data      |
| Audit Trail          | Records all modifications    |
| Output Security      | Prevents unauthorized access |
| Diskless Workstation | Reduces risk of data theft   |

## Must-Memorize Terms 🚀

- **HCI** = Human-Computer Interaction
- **UI** = User Interface
- **GIGO** = Garbage In, Garbage Out
- **Input Mask** = Restricts input format
- **Audit Trail** = Records system activities
- **Exception Report** = Shows records meeting conditions
- **Control Field** = Used for sorting in control break reports
- **Report Footer** = End-of-report totals and summaries
- **Output Security** = Protects confidential output
