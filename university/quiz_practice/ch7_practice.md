# Important Concepts 🌸

## RFQ vs RFP

| RFQ                                           | RFP                                        |
| --------------------------------------------- | ------------------------------------------ |
| Request for Quotation                         | Request for Proposal                       |
| Used when company already knows what it wants | Used when company needs detailed solutions |
| Focuses on pricing                            | Focuses on full solution proposal          |

---

## SaaS vs ASP

| SaaS                          | ASP                              |
| ----------------------------- | -------------------------------- |
| Software accessed online      | Full operational software rental |
| Usually subscription-based    | Provider manages application     |
| Less maintenance for customer | Includes support and operations  |

---

## Outsourcing vs In-House Development

| Outsourcing                              | In-House                          |
| ---------------------------------------- | --------------------------------- |
| External company develops/manages system | Company develops internally       |
| Can reduce costs                         | Faster response to business needs |
| Depends on vendor quality                | More organizational control       |

---

## TCO (Total Cost of Ownership)

TCO includes:

- Hardware costs
- Software costs
- Maintenance
- Training
- Support
- Upgrades
- Operational expenses

About 80% of total costs happen after purchase ✨
